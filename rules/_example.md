# User Rules 示例（草稿，不会注入）

以 `_` 开头的文件视为草稿/模板，**不会**进入 system prompt。

要启用文件规则：把本文件复制为例如 `naming.md`（去掉前缀 `_`），按需改内容。

## 写法建议

- 写清楚「必须 / 禁止」的可执行约定
- 避免与 Ask 只读、危险确认等产品安全策略冲突
- 单条规则尽量短；总注入长度有上限（默认 8000 字符）

## 示例内容

```
- 网格命名使用 SM_ 前缀，骨骼使用 SK_
- 导出 FBX 默认到工程 Export/ 目录，嵌入贴图
- 角色绑骨优先 UE5 模板，最大影响数 4
```
